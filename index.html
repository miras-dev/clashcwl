How do I get my JSON?

1. Create a free account at developer.clashofclans.com and generate an API key.
2. Call GET https://api.clashofclans.com/v1/players/%23YOURTAG with the key.
3. Paste the whole response here. Sites like Clash of Stats or Discord bots (ClashKing) can also export this JSON for you.
Note: the official API exposes heroes, equipment, troops and spells — defense levels aren't public, but if your JSON includes a buildings array (from a layout-export tool) we'll show those too.
